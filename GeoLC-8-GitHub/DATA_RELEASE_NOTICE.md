# Data release notice

The local GeoLC-8 directory is ready for reproducibility work, but this does
not by itself grant permission to redistribute the underlying commercial or
institutional imagery.

- `pipeline/data/tiles/images`, `pseudo_labels/labels`, and
  `pseudo_labels/confidence` are local symbolic links to the audited raster
  corpus.
- The manifests, quality-control records, split assignments, code, and model
  hashes are included directly in this release.
- Before a public upload, verify the redistribution terms of every source
  provider and assess the privacy and security implications of publishing
  georeferenced disaster-response imagery.
- If raw imagery cannot be redistributed, publish the manifests and exact
  regeneration procedure with an access route authorized by the providers.

No code or data license is assigned in this prepared directory. A license
should be selected only after ownership and redistribution permissions have
been confirmed.
